# hdd_size.sh 2.1-postfix

Контроль заполнения диска на production `discount-tools.ru`. При достижении порога (90%) удаляет **только содержимое** `/var/www/discount-tools/public/bitrix/cache` и проверяет заполнение диска после очистки. Создание кеша параллельным PHP-FPM может вызвать `Directory not empty`: сообщение фиксируется в журнале, но успешность определяется итоговым `df`.

## Файлы

- `hdd_size.sh` — исполняемый скрипт;
- `examples/hdd_size.conf.example` — все настраиваемые параметры;
- `examples/root.cron.example` — запуск каждую минуту;
- `logrotate/hdd_size` — ротация журнала;
- `MIGRATION.md` — установка на production.

## Режимы

- `--check` — показывает параметры, состояние, процент диска; ничего не меняет;
- `--dry-run` — сообщает, потребовалась бы очистка, без изменения state, отправки писем и удаления;
- без аргументов — рабочий запуск (при заполнении >= THRESHOLD).

Письма отправляет локальный Postfix через `SENDMAIL=/usr/sbin/sendmail`. При нормализации уровня записывает `OK`. При сохранении превышения после очистки записывает `ALERT` и возвращает ненулевой код, письма повторно каждую минуту не шлёт. Нагрузка при пересоздании кеша может кратковременно вырасти.

**Безопасность:** конфиг — Bash-файл, редактировать только root; команда проверяет, что путь очистки заканчивается на `/bitrix/cache`. Не используйте неизвестные пути и не запускайте на боевом сервере до чтения `--check`.
