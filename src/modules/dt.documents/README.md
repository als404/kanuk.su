# dt.documents — Git-снимок 0.1.2 + исправления production (10.11.2026)

**Для отдельного локального репозитория, не для распаковки на сайт.** Исходники сайта и Git-хранилище у пользователя находятся в разных папках. Снимок не является автоматическим экспортом действующего production: перед коммитом обязательно сверить изменённые файлы с рабочим сайтом.

## Куда копировать

В **корень отдельного Git-репозитория**, открытого в VSCode:

```text
<repo>/
├── src/
│   ├── modules/
│   │   ├── dt.catalogproperties/    # уже существует, не затрагивать
│   │   └── dt.documents/            # исходники модуля из пакета
│   └── addition_include/            # уже существует; сравнить перед заменой
│       └── addition_include.js      # JS текущего переходного периода
├── docs/                             # документация и задачи
├── tests/                            # проверочные сценарии
├── snippets/                         # фрагменты изменений шаблона сайта
└── deploy/upload/doc/addition_include.js  # копия JS для deployment-reference
```

В вашем репозитории уже есть `src/modules/` и `src/addition_include/`: **папки не удалять и не заменять целиком**, переносить и сравнивать отдельные файлы. Прочие модули и файлы остаются без изменений.

Фактические пути на сервере (это **не** Git-пути):
- `src/modules/dt.documents/` → `/var/www/discount-tools/public/local/modules/dt.documents/`
- `src/addition_include/addition_include.js` → `/var/www/discount-tools/public/upload/doc/addition_include.js`

`snippets/` описывает три дополнительные правки проекта: `catalog/.default/element.php`, дочерний шаблон `catalog.element/.default/template.php`, `/catalog/index.php`. В этот пакет их **полные production-версии не включены**. Скопируйте актуальные файлы в принятую структуру вашего локального репозитория через VSCode, затем сравните diff.
