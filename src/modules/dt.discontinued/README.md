# DT Discontinued Products — 1.0.0

Интеграционная разработка для discount-tools.ru. Снимок production от 25.11.2026. Битрикс 17.5.8, PHP 7.4, шаблон `elektro_flat`, кодировка UTF-8. Это не устанавливаемый модуль Битрикс; путь `src/modules/dt.discontinued/` используется только для хранения в Git.

## Назначение

Товар, снятый с производства, сохраняет активность, URL и SEO. Отображается жёлтая плашка на изображении в соответствующих карточках, текстовый статус в детальном представлении, быстром поиске и сравнении. В плитке каталога оставлена плашка без дублирования текста. При положительном остатке покупка разрешена в пределах складского количества; при нулевом остатке покупка, заказ и покупка в один клик недоступны в доработанных шаблонах. Обычные товары сохраняют штатное поведение.

| ID свойства | 692 |
| XML_ID значения | Y |

Статус устанавливается администратором вручную. Импорт BREXIT/ESSON обновляет цену, QUANTITY и AVAILABLE, не меняя статус. Числовые ID приведены для исходной базы, не являются универсальными.

## Архитектура

- `local/php_interface/dt_discontinued.php`: определение статуса по XML_ID, чтение остатка, агрегирование количества по ID товара в корзине, запрет увеличения сверх остатка, повторная проверка нового заказа. Уменьшение количества и ранее оформленные заказы не блокируются. SKU-путь предусмотрен, но не тестировался: действующих SKU на сайте нет.
- `bitrix/php_interface/init.php`: регистрация OnSaleBasketBeforeSaved и OnSaleOrderBeforeSaved. Не заменять целиком при интеграции.
- `ajax/add2basket.php`: JSON `SUCCESS`, `MESSAGE`, `STOCK`; обработка отказа сервера. Семь компонентных JS-обработчиков прекращают успешный сценарий при отказе и показывают предупреждение.
- `local/templates/elektro_flat/script.js`: ограничение кнопок +/- и ручного ввода через `data-dt-max-quantity` / `data-dt-quantity-step`. Это интерфейсная проверка, не замена серверной.
- `custom.css`: оформление статуса и плашки.
- `catalog/index.php`, комплексный `catalog/.default/element.php`, `section.php`: передача свойства в компоненты; `catalog.search/.default/template.php`: принудительный плиточный режим `table`.
- `catalog.element/.default` и `catalog.element/my_default`: детальная карточка и быстрый просмотр; `ajax/fast_wiu.php` передаёт свойство.
- `catalog.section/table`, `catalog.section/filtered`, `catalog.bigdata.products/.default`: плитка, похожие товары / аксессуары и рекомендации; исключение недоступных отмеченных товаров из инициализации покупки там, где предусмотрено.
- `altop/search.title/.default`: полный локальный шаблон быстрого поиска; фиксированная `GUARANTEE` исключена из SELECT_PROPS, обычная покупка напрямую; формат PROPS согласован с endpoint; отключён локальный JS-кэш результатов.
- `catalog.compare.result/.default`: сравнение и изолированный JS-класс.
- `ajax/search_title_popup.php`, `ajax/catalog_compare_popup.php`: сохранённые точки входа дополнительных параметров; POST, проверка sessid, подпись Bitrix Signer с отдельными salt, срок 1800 секунд, привязка к сессии, ограничение размера и безопасное десериализование без классов. Прямой доступ к скрытым шаблонам не требуется.

## Структура репозитория

```text
src/modules/dt.discontinued/
  README.md
  MIGRATION.md
  CHANGELOG.md
  TESTING.md
  MANIFEST.txt
  SHA256SUMS.txt
  integration/             # извлечённые блоки общих файлов
  files/                   # 49 файлов сайта, пути от DOCUMENT_ROOT
  scripts/                 # 2 исторических скрипта миграции
```

`MANIFEST.txt` перечисляет 49 путей относительно корня сайта. `SHA256SUMS.txt` сохраняет оригинальные суммы 51 исходника. `integration/` содержит точные текстовые фрагменты для ручного слияния, а не дополнительные исполняемые модули. Проверка на Mac: `shasum -a 256 -c SHA256SUMS.txt`.

## Зависимости и ограничения

Снимки включают существующий код Altop, dt.catalogproperties, dt.documents, SEO, дилерское меню, сортировку и прочие функции сайта. Не использовать как независимый дистрибутив и не перезаписывать общие файлы без сравнения. Публиковать только в репозитории с разрешённым доступом к этому коду; отсутствие найденных явных секретов не гарантирует возможность публичного распространения.

Известные ограничения и результаты испытаний: [TESTING.md](TESTING.md). Установка и перенос: [MIGRATION.md](MIGRATION.md).
