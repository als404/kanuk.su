# dt_catalog_sort — сортировка каталога 1С-Битрикс, V4.4

**Статус:** код V4.4 и интеграция V4.3 проверены на тестовом сервере `discount-tools-test` (192.168.15.247) 13.11.2026. **Сборка в Git не является разрешением развёртывания на production.** Текущие CLI/кеш-классы **преднамеренно разрешают запись и удаление файлов только на тестовом сервере**; адаптация к production описана в [MIGRATION.md](MIGRATION.md) и требует отдельного ревью.

## Как сортируется каталог

- **По умолчанию:** доступность определяется параметром компонента; BREXIT → ESSON → прочие; внутри каждой группы товары с положительной ценой раньше товаров без цены, цена возрастает.
- **По цене:** все товары независимо от производителя сортируются глобально по эффективной цене ASC/DESC, отсутствующая/нулевая цена помещается в конец (свойство `DT_SORT_ZERO`).
- **По рейтингу:** сохраняется отдельный режим с группировкой.
- Учитываются пользовательская группа 2, сайт `s1`, `RUB`, скидки на момент пересчёта. `--sweep=0` не отслеживает **изменение скидки только по времени**; это отдельная незавершённая задача.

## Схема обновления

1. Изменение через Битрикс вызывает событие и ставит ID в `dt_catalog_sort_queue`.
2. Прямые SQL-записи из `cost_update` не вызывают события Битрикс; для них необходима **отдельная интеграция V4.3** (см. [MIGRATION.md](MIGRATION.md)).
3. CLI worker запускается из cron и обновляет `DT_SORT_GROUP`, `DT_SORT_PRICE`, `DT_SORT_ZERO`.
4. Worker очищает тегированный кеш Битрикс и существующие `index@*.html` соответствующих разделов/карточек.
5. Только после успешной очистки задача удаляется по `PRODUCT_ID` и `VERSION`; при ошибке сохраняется для повтора.
