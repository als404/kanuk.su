# История изменений

- **V3:** `DT_SORT_ZERO`, эффективная цена, групповая сортировка, отдельный глобальный режим «По цене», фрагменты `section.php`.
- **V4.2:** события Битрикс, очередь `dt_catalog_sort_queue`, worker cron, статус, выборочный и полный пересчёт, выключение полного обхода через `--sweep=0`.

- **Git-упаковка 13.11.2026:** объединены исходные файлы V3+V4.4, сохранены тестовые побайтные версии PHP V4.4, добавлены миграция/протокол и отдельный опциональный git patch V4.3.
